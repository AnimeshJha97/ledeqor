# Module 15: Resume, LinkedIn & Job Strategy

## Module Purpose

This module helps reposition your public profile.

You should not look like a MERN developer randomly trying AI. You should look like a senior full-stack engineer who is now building production-grade applied AI systems.

## Learning Outcomes

By the end of this module, you should be able to:

- rewrite your resume for AI-adjacent roles
- add AI skills honestly
- describe Orvion DocIntel as project proof
- update LinkedIn headline and about section
- clean up GitHub
- create a portfolio case study
- write a demo video script
- send referral and cold DM messages
- filter roles intelligently
- run a weekly application tracker

## Final Mini Build

Create:

- AI-focused resume version
- LinkedIn headline
- LinkedIn about section
- Orvion DocIntel project section
- GitHub README polish
- portfolio case study
- demo video script
- application tracker

---

## 15.1 Resume Positioning For AI Roles

Target positioning:

```text
Senior Full Stack Engineer | React, Node.js, Python, FastAPI, LLMs, RAG, AI Workflows
```

The story is expansion, not reinvention.

## 15.2 Updating Professional Summary

Example:

"Senior Full Stack Engineer with 5 years of experience building React, Node.js, and TypeScript products. Expanded into applied AI engineering through production-style document intelligence systems using Python, FastAPI, LLM APIs, embeddings, vector search, RAG, structured extraction, workflow automation, and evaluation."

## 15.3 Adding AI Skills Without Sounding Fake

Use skills you can explain:

- Python
- FastAPI
- LLM APIs
- prompt engineering
- structured outputs
- embeddings
- vector search
- RAG
- pgvector
- AI evaluation
- document AI

Avoid claiming deep ML research unless you have proof.

## 15.4 Writing Orvion DocIntel Project Section

Resume bullet:

"Built Orvion DocIntel, a document intelligence SaaS that uploads business documents, extracts structured fields, performs semantic search, answers questions with citations, compares documents, and runs AI workflows using Python, FastAPI, LLM APIs, embeddings, pgvector, RAG, Redis queues, and a Next.js dashboard."

## 15.5 Rewriting LinkedIn Headline

Options:

```text
Senior Full Stack Engineer | Applied AI, LLMs, RAG, Python, FastAPI, React, Node.js
```

```text
Senior Full Stack Engineer building AI document intelligence systems with LLMs, RAG, and full-stack SaaS architecture
```

## 15.6 Rewriting LinkedIn About Section

Structure:

1. Current identity.
2. Full-stack strength.
3. Applied AI expansion.
4. Orvion DocIntel proof.
5. Target roles.

Video structure:

1. Problem overview.
2. Upload document.
3. Show extraction.
4. Ask cited question.

6. Compare documents.
7. Explain architecture.

## 15.10 Cold DM Strategy

Message:

"Hi [Name], I am a senior full-stack engineer expanding into applied AI. I recently built a document intelligence SaaS using Python, FastAPI, LLMs, embeddings, RAG, and Next.js. I noticed your team works on [specific area]. Would love to connect and learn if applied AI/full-stack roles may be opening."

## 15.11 Referral Message Strategy

Keep it easy to forward:

- who you are
- target role
- project proof
- resume link
- portfolio link
- role link

## 15.12 Role Filtering Strategy

Target:

- AI Engineer
- Applied AI Engineer
- Full Stack AI Engineer
- LLM Engineer
- AI Product Engineer
- Backend Engineer, AI Platform

Avoid roles requiring deep research-only experience unless the posting fits your proof.

## 15.13 Salary Discussion Strategy

Anchor on:

- 5 years full-stack experience
- AI product capability
- production architecture
- business-facing delivery

Do not position as entry-level AI.

## 15.14 Weekly Application Tracker

Track:

- company
- role
- source
- referral contact
- date applied
- status
- follow-up date
- notes

## 15.15 How To Apply With Project Proof

Application package:

- tailored resume
- short note
- Orvion DocIntel link
- GitHub link
- demo video
- architecture diagram

Proof beats claims.

## Resume Project Bullet Set

- Built a full-stack AI document intelligence SaaS with Next.js, Node.js, Python, FastAPI, PostgreSQL, pgvector, Redis queues, and object storage.
- Implemented document upload, parsing, classification, structured extraction, semantic search, RAG Q&A with citations, and controlled AI workflows.
- Designed evaluation datasets for extraction accuracy, retrieval quality, hallucination checks, citation correctness, latency, and token usage.
- Added security patterns including workspace isolation, RBAC, safe logging, prompt injection defenses, and document deletion workflows.

## Answer Key

1. Senior full-stack engineer building applied AI products.
2. You must be able to explain every claimed skill.
3. End-to-end AI product architecture and implementation.
4. README, screenshots, demo, architecture, setup, evals, security, roadmap.
5. Applied AI Engineer, Full Stack AI Engineer, AI Product Engineer, LLM Engineer, AI Platform roles.
6. It reduces doubt and gives interviewers concrete material.
