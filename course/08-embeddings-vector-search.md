# Module 6: Embeddings, Vector Search & Semantic Search

## Purpose

Learn the retrieval foundation of RAG: embeddings, chunking, vector databases, metadata filters, hybrid search, and reranking.

## Mini Build

- Chunk extracted document text
- Generate embeddings
- Store chunks in vector database
- Search documents using natural language
- Return matching chunks
