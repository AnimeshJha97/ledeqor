# Module 5: Structured Document Extraction

## Purpose

Turn documents into useful business data using extraction schemas, JSON outputs, validation, confidence scoring, and human review.

## Mini Build

- Create extraction schemas
- Extract fields from invoices
- Extract fields from contracts
- Validate with Pydantic
- Store extracted data
- Show extracted fields in dashboard
