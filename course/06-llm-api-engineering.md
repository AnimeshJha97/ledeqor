# Module 4: LLM API Engineering

## Purpose

Learn how to use LLM APIs professionally with structured outputs, retries, streaming, fallback, cost control, prompt versioning, and validation.

## Mini Build

- Document summarizer
- Document type detector
- Invoice field extractor
- Contract summary generator
- Policy document Q&A prompt
