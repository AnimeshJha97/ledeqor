# Module 3: Document AI Fundamentals

## Purpose

Understand why document intelligence is harder than normal chatbot development and learn the foundations of PDF, OCR, layout, metadata, and document classification.

## Mini Build

- Upload PDF
- Detect file type
- Extract text
- Extract document metadata
- Detect whether document is scanned or digital
- Return clean extracted text
